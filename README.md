# SWT Driver Site

Бесплатный статический сайт SWT Driver для GitHub Pages.

## Публикация
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

## Перед полноценным запуском
- Подтвердить официальные ссылки SWTCalcBot и SWTCashBot и способ покупки комплекта.
- Уточнить периодичность тарифов и правила пробного периода.
- После публикации указать канонический URL и создать sitemap.xml.
- Подключить Google Search Console и Яндекс Вебмастер, затем аналитику.

Код Telegram-ботов не используется и не изменяется.
